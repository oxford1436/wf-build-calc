## 메타와 다른 이유 (P7, 숫자)
1. **프라임드 슈레드(관통)** — 두 무기 모두 가장 큰 차이. 소마 HighGround 포인트 스트라이크 → 프라임드 슈레드 ×2.1, 고트바 Shacknews 비질란테 아마먼트 → 프라임드 슈레드 ×1.36. 계산기의 무리 모델(뒤에 줄 선 적 평균 2명, 사람 몸 0.6m)에서 관통 2.2m가 한 발에 약 3명을 맞힘 + 연사 +55%. 아카라이브 "돌격소총은 관통이 있어야 섬멸"(179928089)과 같은 결론 ✅. 영문 글 4개 중 1개만 슈레드를 넣음.
2. **마그네틱 캐퍼시티(자성)** — 커뮤니티 4개 모두 자성 없음. 고트바 1위에서 빼면 66~73%, 엑시무스를 빼면 88~95%, 그리니어·엑시무스 없음 92~99% → 자성 몫의 대부분이 무리에 섞인 엑시무스 1명의 오버가드(Lv150 약 28만). 테넷 아르카 플라즈모어 마그네틱 스트레이프와 같은 패턴(0c). 엑시무스 기본 포함은 사용자 결정이라 그대로 두고, 오버가드 크기(12×(1+260×(레벨−1)^0.9))는 대기열 21에서 확인.
3. **플레이티드 라운드 vs 머시리스** — 1위 모드 그대로 머시리스면 소마 81%, 고트바 87%. 위키 표(탄창 80 → 300%, 200 → 474%, "additive to base damage such as Serration", 10초)와 엔진이 같음 ✅. 커뮤니티는 머시리스(처치 중첩), 커뮤니티 글은 "10초마다 재장전" 부담만 언급 △.
4. **헌터 뮤니션즈** — 소마 커뮤니티 2/2, 고트바 1/2. 계산기에선 1위 칸을 바꾸면 소마 66%, 고트바 62%. 커뮤니티 세팅은 피해 모드(서레이션·갈바나이즈드 앱티튜드)나 아케인이 빠진 경우가 많아 상대적으로 베기 비중이 커짐. △
5. **라임 라운즈 vs 프라임드 크라이오 라운즈** — 고트바 ×1.26. 라임(냉기 60%+상태이상 60%) 대신 프라임드 크라이오(냉기 165%) — 1위 상태이상은 81%로도 충분.
