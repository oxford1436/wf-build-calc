## 계산기에서 고친 것 (v1.88)
1. **빔 끝점 범위 피해**(위키 노트: 글랙시온 반달 "damaging cold blotch in a spherical radius of 2 meters … Not affected by multishot … full damage (no falloff)", 이그니스·이그니스 레이스 3m, 리지 4m, 카타볼리스트 0.7m, 엠볼리스트 1m)가 계산에 없어서 이 무기들은 추천 보류 상태였음 → 빔 + 끝점 범위(멀티샷 미적용·감쇠 없음)를 합친 기본 공격. 빔에 맞은 적도 범위를 받는지는 위키에 없음 → 받음(기본) / 안 받음(`o.noBeamAoe`) 양끝 계산. 글랙시온 반달 그리니어(서레이션·스플릿 체임버)에서 받음/안 받음 ×2.31.
2. **판타즈마·판타즈마 프라임 기본 공격**이 보조 사격(충전 플라즈마 폭탄)이었음 → 주 사격 빔. 빔 피해 상승 15% → 100%(0.6초)도 'Beam' 이름 때문에 빠져 있었음 → 적용. 같은 이유로 **퀀타 3종** 빔 상승(30% → 100%)도 v1.74부터 빠져 있었음 → 적용.
3. 카타볼리스트 기본 공격이 재장전 수류탄이었음 → 빔(수류탄은 따로 고름).
4. 몸통 무한 관통(이그니스·레이스·판타즈마 2종)은 이미 계산됨(convert.py INF_BODY_PT) — 감사 표시만 handled로.

## 메타와 다른 이유 (P7)
- **마그네틱 캐퍼시티**(빼면 67%): 다른 묶음과 같은 패턴 — 자성 칸 몫 대부분이 무리 속 엑시무스 오버가드(대기열 21에서 확인 예정). 커뮤니티 세팅 2개 모두 없음.
- **스피드 트리거**(빼면 72%): 빔 끝점 범위가 맞은 적에게도 들어간다는 기본 가정에서 연사 가치가 커짐. 안 받는 쪽에서는 1위에서 빠짐 → 이 차이 때문에 보류.
- **아케인**: 커뮤니티 머시리스 vs 계산기 플레이티드 라운드 — 처치 중첩을 무리마다 0부터 쌓는 사용자 결정 때문(중첩 유지면 머시리스 쪽 64.7%로 차이 줄어듦). 다른 묶음과 같음 △.
