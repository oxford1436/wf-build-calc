# 리벤을 맞출 무기 고르기 — 2026-11-17

사용자 질문: 주무기(보어 프라임·스트런 프라임)와 보조무기(레이텀·쿠바 뉴코어·듀얼 톡소시스트) 중 최강 리벤을 맞췄을 때 가장 높은 무기와 그 최종 세팅.

- 주무기는 **사이트-09 전용**(아스날 화면: 위력 298%·지속 226%·거리 34%·효율 45%, 타우포지드 보라 샤드 4개 + 타우포지드 노랑 1개, 그로잉 파워, 아케인 스컬프터·라이즈, 헬민스 너리시). 용도는 중재 방어·감청에서 **벽 뒤 적 광역 처치**, 인카논 진화만 쓰고 형태는 안 켬.
- 보조무기는 **범용**(워프레임 없음).

## 방법
`run.js`가 계산기 앱 경로(공유 링크 → 자동 계산 → 리벤 '맞출 예정' 단계)를 그대로 돌리고, `sens.js`가 정해진 세팅을 조건을 바꿔 가며 `evalBuild`로 다시 계산합니다. 결과 원본은 `results/`. `plasmor_p4.js`는 v2.17 뒤 세팅 노트의 테넷 아르카 플라즈모어 비교표를 다시 계산한 것(P4).

### 보조무기 조건
계산기 기본값: 강철의 길 Lv150·250·400, 3팩션, 12명 무리(중장갑 1·엑시무스 1), 동반자 본드 모드 켬. 공격은 레이텀 = 인카논 형태 한 발 전체(직격 + 2m 폭발, attack 3), 듀얼 톡소시스트 = 인카논 형태, 쿠바 뉴코어 = 기본 사격(자성 37.8%).

### 주무기: 벽 너머 뿌리기 조건 (계산기에 없는 운용 — `run.js`의 `spray`)
위키 Seek(2026-11-17 읽음): "10 meter Punch Through against enemy bodies", "infinite punch through against terrain". 커뮤니티 설명(아카라이브 188780150): 탄 퍼짐을 광역 공격처럼 써서 벽 뒤 무리를 쓸어 담음.

| 가정 | 값 | 이유 |
|---|---|---|
| 적 | 중재(강철의 길 아님) Lv100·200·350, 3팩션 | 사용자가 중재 계산에 Lv100~300 이상을 요구(CLAUDE.md) |
| 한 발이 맞히는 적 | 무리 12명 전원(`o.hits`) | 원뿔 안의 적이 모두 펠릿 일부를 맞음 |
| 적 한 명이 맞는 펠릿 비율 c | 0.005~0.05 (`pellets × c`) | 모름 — 범위로 계산. 무리 전멸 시간으로는 0.3초(0.05)~4초(0.005) |
| 탄 퍼짐 | 불이익 없음(`spread` 삭제) | 퍼짐이 넓으면 한 명이 맞는 양은 줄고 덮는 면적은 늘어 총량은 같다고 봄 |
| 다시 조준 | 0.01초 | 한 방향으로 계속 뿌림 |
| 거리 감쇠 | 없음 | 익실러스 갈바나이즈드 액셀러레이션(위키: "increases the effective range of shotguns before Damage Falloff takes effect", 최대 +90%) 기준 약 34m 안. 따로 30m·액셀러레이션 없음(보어 ×0.3, 스트런 ×0.88)도 계산 |
| 리서플라이 | 전기(커뮤니티 기본), 시전 0초 | 다른 원소·시전 0.15초는 따로 계산 |
| 무리 밀도 | 기본(3m 안 1.9명), ×3, ×6 | 스폰 지점에 뭉친 무리 = 전기 연쇄가 더 많이 닿음 |

c가 작고 무리가 뭉칠수록 전기 도트 몫이 커져 '전기 세팅'(프라임드 차지드 쉘·샷건 엘리멘탈리스트·상태이상 피해 리벤)이 올라오고, c가 크면 직격 치명타 세팅이 앞섭니다. 그래서 한 조건의 1위가 아니라 **조건 전체에서 고르게 강한 세팅**을 골랐습니다.

스트런 프라임 진화 II 블레이징 배럴(기본 멀티샷 +0.25)은 펠릿을 줄인 뒤에 더해져 과대평가되므로 스트런은 테노 타겟팅으로 다시 계산했습니다(실제 차이 2% 이하).

## 화면 대조 (P5)
보조무기 세 개의 아스날 수치(치명타 확률·배율, 상태이상, 멀티샷, 연사)는 계산기와 일치(터네이셔스·리인포스드 본드 포함). 듀얼 톡소시스트: 진화 II 카니지 레인·IV 코모도어즈 포춘으로 확인. 총계 1,217.5는 표시된 피해 합 519.75 × 멀티샷 2.1 = 1,091.5와 달라 원인 미확인(멀티샷으로는 발당 60 차이).

## 남은 불확실성
- c와 무리 밀도는 가정. 8번 칸(칠링 그래스프 ↔ 포인트 블랭크)과 리벤 세 번째 옵션의 2·3위가 여기에 달림 — 가장 드문 명중 + 뭉친 무리(c 0.005, 밀도 ×3)에서는 포인트 블랭크·샷건 엘리멘탈리스트 쪽이 4~9% 앞섬.
- 리서플라이 에너지: 시전 무제한으로 계산. 최종 세팅은 탄창 20발을 약 1초에 비워 그때마다 시전(스컬프터 효율 175%면 12.5 에너지). 탄약 효율 리벤은 시전을 2.26배 줄이지만 처치 속도 −14~28%.
- 보어 리이파이드 베인의 +10·+14가 펠릿당인지는 위키에 없음(스트런은 펠릿당이라고 적혀 있음) — 계산기는 펠릿당. 아스날에서 진화를 고르면 피해 320(40 × 8)이 400이 되는지로 확인. 합계 기준이면 보어 우위가 10% 안쪽(독립 검토 지적).
- 시크 약점 피해(+75%, 탐지된 적 헤드샷)·아비트레이션 드론·무기 보너스(+300%)는 미반영.
- 계산기 기본 공격이 레이텀은 '인카논 형태'(직격만)로 잡힘 — 폭발까지 합친 공격(attack 3)이 `alt`라 기본에서 빠짐. 이 계산은 attack 3.
- 독립 검토(서브에이전트, 2026-11-17): 프라임드 블런더버스 문제, 보어·스트런 차이가 작다는 점, 레이텀 리벤 세 번째 옵션·접합의 값이 2% 이내, 보어에 익실러스 어댑터가 필요하다는 점을 지적 → 반영.
