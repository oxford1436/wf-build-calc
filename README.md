# 워프레임 세팅 계산기 (wf-build-calc)

무기·상황·워프레임 버프·리벤을 고르면, 장착 가능한 모든 모드 조합 중 **가장 빨리 죽이는 세팅**을 찾아 주는 단일 HTML 페이지입니다.

- 페이지: `index.html` (빌드 결과, 그대로 열면 됩니다)
- 데이터: [WFCD/warframe-items](https://github.com/WFCD/warframe-items) (위키 기반, 공식 한국어 이름 포함) + 위키 `Module:Weapons/data` (최대 탄약·탄약 소모·확정 상태이상·투척 속도·극성·최대 랭크·저격 줌/콤보·익절티드 무기) + 위키 `Module:Modular/data` (자우·킷건 부품)
- 계산: 위키 피해 공식 + 적 레벨 공식으로 처치 시간을 시뮬레이션

## 구조
- `src/engine.js` 피해·처치 시간 모델과 탐색기
- `src/mods.js` 피해 관련 모드·아케인 수치 (손으로 입력, 패치 시 갱신)
- `src/buffs.js` 워프레임 어빌리티·헬민스·아콘 샤드
- `src/app.js`, `src/shell.html` 화면
- `src/ocr.js` 비교 세팅의 '스크린샷으로 채우기' (브라우저 안에서 tesseract.js로 글자 인식 → 모드·아케인 이름 대조)
- `src/guide.js`, `src/guide_list.js`, `data/guides/*.json` '워프레임 가이드' 탭 (어빌리티 역할·능력치 우선순위·위키 공식으로 확인한 브레이크포인트·지역별 커뮤니티 추천 세팅, 프레임당 JSON 한 개)
- `src/changelog.js` 버전·패치 내역 (페이지 맨 위 버전 표시와 '패치 내역' 탭, 주소 끝 `#patch`). 고칠 때마다 맨 앞에 항목을 추가합니다.
- `src/convert.py`, `src/convert_frames.py`, `src/wiki_lua.py` WFCD·위키 데이터 → 계산기용 데이터
- `scripts/fetch_data.sh` 최신 데이터 내려받기, `scripts/build.sh` 빌드

## 갱신
GitHub Actions가 매주 월요일 최신 데이터를 받아 `index.html`을 다시 만듭니다 (`.github/workflows/update.yml`).
수동으로는 `scripts/fetch_data.sh data/raw && scripts/build.sh`.

## 계산에 들어가는 것 (요약)
- 모드 전부(최대 랭크), 원소 합성 순서, 무기·워프레임 아케인, 아콘 샤드, 오라, 어빌리티·증강(로어·이클립스·슈팅 갤러리·워크라이·페넌스·커버넌트·앰프·원소 증강 등), 포커스·중재·은신 버프
- 모드 용량·극성·포르마(오로킨 카탈리스트 기준, 포르마 한도 옵션), 비질란테·글래디에이터·새크리피셜 세트 보너스
- 저격총 줌 보너스·저격 콤보, 익절티드 무기(어빌리티 위력 반영), 자우·킷건 직접 조립
- 탄약 지속 시간과 탄약 보완 세팅, 거리·폭발 가장자리 감쇠, 오버가드
- 비교 세팅은 아스날 스크린샷을 올리면 모드·익실러스·아케인·리벤 수치를 읽어서 채웁니다 (첫 사용 시 인식 도구 약 6MB를 jsDelivr에서 받음)

## 한계
- 과잉 피해는 처치 시간 방식으로 반영합니다. 엑시무스 오버가드는 중장갑 상황에서 선택 사항, 코퍼스 실드 회복·근접 자세 콤보 차이는 계산하지 않습니다.
- 치명타는 기대값(평균)으로 계산하고, 반동·명중 퍼짐·투사체 비행 시간은 넣지 않습니다.
- 모드 수치(`src/mods.js`)와 어빌리티 수치(`src/buffs.js`)는 수동 관리입니다. 틀린 값을 발견하면 이슈로 알려 주세요.
- 자우 강공, 킷건 폭발 부분 분리, 크로매틱 블레이드 원소 변환, 익절티드 블레이드 검기는 위키에 수치가 없거나 모델이 복잡해 아직 넣지 않았습니다.
